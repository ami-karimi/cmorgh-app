# طراحی یکپارچه رابط سیمرغ

## هویت بصری

- زمینه: `#080f1d`، سطح کارت: `#111c2e`، سطح بالاتر: `#17253a`، حاشیه: `#243247`.
- رنگ برند: `brand-500` (`#3b82f6`) و اکشن اصلی: `brand-600` (`#2563eb`).
- سبز برای موفقیت، زرد برای هشدار و قرمز برای خطا حفظ می‌شوند؛ این رنگ‌ها نباید جای رنگ برند استفاده شوند.
- فونت مشترک: IRANSans محلی در دو فایل WOFF2 با `font-display: swap`؛ درخواست فونت خارجی حذف شده است.
- RTL، دکمه‌های حداقل ۴۴ پیکسل در اجزای مشترک، focus-visible، لینک پرش به محتوا و کاهش حرکت برای prefers-reduced-motion.
- طراحی فعلاً dark-first است؛ تغییر تم روشن/تیره در این مرحله اضافه نشده است.

## اجزای مشترک

- `resources/css/app.css`: توکن‌های رنگ و اجزای `ui-*`.
- `components/ui/brand.blade.php`: لوگو و نام برند، با حفظ تنظیمات فعلی.
- `layouts/partials/site-shell.blade.php`: پوسته مشترک صفحه اصلی، ورود، راهنما و فروشگاه؛ app/store از آن استفاده می‌کنند.
- `components/ui/announcements.blade.php` و کلاس View Component: اطلاعیه‌های فعال واقعی با هدف all/agents/customers؛ حداکثر پنج مورد. شمارنده به معنی خوانده‌نشده نیست.
- `layouts/partials/ui-feedback.blade.php` و `resources/js/ui.js`: پیام‌های Toast و کپی به کلیپ‌بورد. هر دو فرمت رویداد موجود Livewire پشتیبانی می‌شوند؛ متن پیام با textContent درج می‌شود.

## محدوده تغییر

رنگ‌ها، فونت، کارت‌ها و قواعد بصری در قالب‌های پنل مدیریت، نماینده، مشتری، فروشگاه و راهنما یکپارچه شده‌اند. صفحه اصلی و کارت‌های پلن بازطراحی شده‌اند. اکشن‌های VPN، سفارش، پرداخت، دیتابیس واقعی و تنظیمات محیط دست‌نخورده‌اند. برای نمایش ظاهری داده ساختگی به محیط واقعی اضافه نشده است. داده‌های تست صرفاً در SQLite حافظه‌ای هستند.

بخش‌های داخل پنل در تست رندر بررسی شده‌اند؛ گردش کامل خرید/پرداخت، عملیات روی تجهیزات و همه صفحات احراز هویت‌شده تست E2E نشده‌اند. مشکلات امنیتی گزارش‌شده قبلی، از جمله کانفیگ‌های عمومی و مسیر convert، خارج از این مرحله باقی مانده‌اند.

## اعتبارسنجی

```sh
npm run build
php artisan view:cache
php artisan test --filter=UiPresentationTest
node --test tests/js/ui.test.mjs
git diff --check
```

۷ تست PHP (۶۱ assertion) و ۵ تست JavaScript برای رندر پوسته‌ها، لینک حساب بر اساس نقش، اطلاعیه‌ها، escaping و سازگاری پیام‌ها افزوده شده است.

تست پیش‌فرض `Tests\Feature\ExampleTest` با اجرای کل suite به دلیل نبود جدول users در SQLite حافظه‌ای شکست می‌خورد. تست پیش‌فرض و migrationهای پروژه در این مرحله تغییر داده نشده‌اند.

صفحه اصلی و ورود در مرورگر مشاهده شدند؛ صفحه اصلی در عرض‌های ۳۶۰ و ۱۰۲۴ پیکسل overflow افقی نداشت. باز/بسته‌شدن منوی موبایل با Escape و نمایش ایمن Toast نیز کنترل شد.
